# 🚀 Bob Bootcamp


Welcome to the **Bob Bootcamp** - a growing collection of hands-on labs for IBM Bob. Each lab is self-contained and built around a real-world task, so you can start anywhere that matches your current goal.

---

## 🎯 What This Is

A practical, lab-driven training series that shows you how to use IBM Bob effectively - from connecting design tools to your IDE, to building custom modes, automating workflows, and more. Labs are added progressively; check back as new content lands.

---

---

## 🚀 How to Use These Labs

1. 🗺️ **Pick a lab** from the table above that matches your current need.
2. 📋 **Read the prerequisites** section inside the lab before starting.
3. 🔢 **Follow the steps** in order - each step has a check so you know when to move on.
4. 🤖 **Use Bob** while you work through the lab - that's the point.

---

## 📋 General Prerequisites

Most labs assume:

- 🧠 **Bob IDE** installed and running
- 🐙 **Git** - for any labs that involve repositories
- 💻 **A terminal** - PowerShell, bash, or zsh depending on your OS

Each lab lists its own specific requirements at the top.
